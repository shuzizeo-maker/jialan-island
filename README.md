# 嘉蘭樂學島（3D 群島版）

純靜態網站，不需要伺服器或資料庫。教材可以放在 Google 試算表，由各科老師自己維護。

## 檔案
- `index.html`：網站入口
- `assets/config.js`：設定檔，貼上「總表」Google 試算表的網址
- `assets/main.js`：3D 群島、面板、課程視窗、練習題、讀取試算表
- `assets/style.css`：版面與外觀
- `data/g6-chinese.js`：備用的本機教材。總表登記了同一個年級科目後，網站會改用試算表的內容
- 舊版的 `assets/app.js` 已不再使用，可以刪除

## 教材試算表怎麼運作
1. 管理者把「嘉蘭樂學島_總表.xlsx」上傳到學校的 Google 雲端硬碟，用 Google 試算表開啟，共用設定改成「知道連結的任何人：檢視者」，把網址貼進 `assets/config.js`，重新上傳網站一次。
2. 各科老師複製「嘉蘭樂學島_科目範本.xlsx」，用 Google 試算表填寫，共用設定同樣改成「知道連結的任何人：檢視者」，把網址交給管理者。
3. 管理者在總表登記，確認後把「上線」改成「是」。之後老師修改試算表，網站約 5 分鐘內自動更新，不需要重新上傳網站。

## 網址規則（可做成 QR Code）
`#home` 首頁、`#hub` 嘉蘭國小、`#g1`～`#g6` 年級島、`#g6-chinese` 學習項目、`#g6-chinese-L1` 課次（同一科第二份試算表：`#g6-chinese-2-L1`）、`#list` 清單、`#teacher` 老師專區

## 老師專區
- 預覽模式：顯示還沒上線的內容，方便檢查
- 連線檢查：列出總表每一列能不能讀到
- QR Code：自動產生各島與各課的 QR Code

## 更新網站（Cloudflare Pages）
專案 → Create deployment → 選 Production → 拖入整個資料夾。只有改了網站程式或 config.js 才需要重新上傳；改教材只要改試算表。
